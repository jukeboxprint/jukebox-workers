## 5. Chrome tricks that work

- Bring a tab forward with a screenshot and wait 2 seconds before clicking; first clicks on background tabs get lost.
- Selected browser drops between turns, so select it first each time.
- JS `button.click()` works for Allow once, Cloudflare's Add variable, and connector Connect buttons. It doesn't work for GitHub's final Run workflow, which needs a real click.
- GitHub merge state lags: open the PR twice and wait 9 seconds. The merge box needs Merge pull request, then Confirm merge.
- Tool output containing `=`, `&` or `?` can be blocked: replace those before returning text.
- Keep batches short. A long batch times out and may keep running, so check state before retrying.
